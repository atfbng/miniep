# 课程源码目录重构交付说明

源码按 `code/course0` 和 `code/course1～course12` 组织。`course0` 提供环境信息与可选 NCCL 检查，后续十二个目录分别对应原课程。

每课包含实际需要的本地源码副本、第三方依赖清单和启动说明。整个课程目录可以复制到其他位置；Python 源码导入、子进程入口和内部文件路径均限定在本课目录内。运行仍需满足各课 README 中的 Python、PyTorch、CUDA、Triton 与设备条件。

| 原目录职责 | 新目录位置 |
| --- | --- |
| `examples/` 中的课程示例 | 对应课的 `test/demo.py`，同课额外示例也放在 `test/` |
| `mini_ep/` 中的实现 | 各课自己的 `mini_ep/`，按实际导入依赖保留完整模块 |
| `tests/` 中的正确性测试 | 各课自己的 `checks/` |
| `benchmarks/` 中的基准与分析 | 需要这些实现的课程自己的 `benchmarks/` |
| 第十二课 CUDA/NVSHMEM 扩展 | `code/course12/extensions/nvshmem/` |

仓库根目录原有公共源码和示例已迁移，课程间不使用符号链接或共享源码导入。根目录 README、课程索引、十二课本地正文中的源码位置和启动命令已同步调整。课程正文保留完整代码注释和重要片段的分段解释。

## 源码对应关系

迁移基线为 Git 提交 `9222afe9955e40569e82297a25d4ac4baefbb787`。`code/source_map.json` 及各课的 `SOURCE_MAP.json` 记录原路径、迁移目标、基线提交与文件摘要。

算法模块和示例保留原计算逻辑；调整包括入口路径、测试模块路径、包导出范围，以及将跨课测试拆分到对应课程。包初始化只保留本课使用的导出，避免导入未使用的后续课程模块。拆分后的测试方法逐项与原方法比较语法树；CUDA 扩展与基线逐字节比较。`course0` 的环境示例为新增内容，没有旧版语义比较项。

清单用于本次迁移核对。后续修改课程源码时，应同步更新对应摘要及语义比较规则，或另行保留迁移报告作为历史记录。
